## 1. 现状与差距

首页当前是纯占位：`HomePage.tsx` 只渲染标题 + 统计条占位 + 运行时信息脚注；`StatsBar.tsx` 三个卡片固定显示 `--:--`，没有任何进入模式的能力。数据侧其实已具备基础：`study_stats(date, mode, minutes, pomos)` 表已建，`stats` IPC 已提供 `dayTrend / modeCompare / heatmap`，但缺少"今日汇总 + 连续天数"这一首页需要的聚合口径。

对照 v2.0 §2.2，首页缺口有三处：

| 设计要求（§2.2） | 现状 | 本方案 |
|---|---|---|
| 顶部统计条：今日专注 / 完成番茄 / 连续天数 | 占位 `--:--` | 接入真实数据 + loading 态 |
| 三张模式卡片（视频学习 / 英语 / 专注） | 无，仅侧边菜单可进 | 新增 `ModeCard`，点击进入 |
| 进入前弹出时长配置浮层 | 无 | 新增 `DurationConfigModal` |

> **范围说明**：本文件只负责首页入口与统计条。视频学习/英语模式"进入后的强制锁定"属于文档 ②（视频学习接入强制引擎），此处进入后仅完成页面跳转与时长回传。

## 2. 总体方案

在现有骨架之上新增一气贯通的"数据 → IPC → 状态 → 组件"链路：主进程新增一个聚合查询 `stats:home-summary`，渲染层新增 `homeStore` 承接数据，`StatsBar` 改读真实数据，新增 `ModeCard` 与 `DurationConfigModal` 两个组件，最后重组 `HomePage` 并让 `App` 给它传入导航回调。

```
渲染层                                       主进程
─────────────────────────────                ─────────────────────────────
HomePage.tsx                                   storage/stats.ts（IPC 注册）
  ├─ ModeCard ×3                                │
  ├─ DurationConfigModal                        │
  ├─ StatsBar（读 store）                        │
  └─ homeStore（zustand）                       storage/db.ts · getHomeSummary()
       └─ window.api.stats.homeSummary()  ──▶   │
                                                study_stats 表
onNavigate(mode) ──▶（页面跳转）
```

### 复用现有成果，不重复造轮子

- 今日/连续天数直接从 `study_stats` 聚合，不新增表。
- 进入专注模式复用已有 `focusStore.start('countdown', ms)`（其内部走 `timer:start` → `beginEnforcement`）。
- 模式进入统一走 `App` 的 `setPage`，与侧边菜单共用同一路由。

## 3. 数据层：HomeSummary

在 `src/shared/stats.ts` 新增首页汇总类型，供主进程 / preload / 渲染层共用。

```ts
export interface HomeSummary {
  /** 今日累计专注分钟（study_stats 按 date 聚合） */
  todayMinutes: number
  /** 今日完成番茄数 */
  todayPomos: number
  /** 当前连续学习天数（今天未学则从昨天起算，今天仍计入） */
  streakDays: number
}
```

### 聚合实现（db.ts）

连续天数的口径：**只要今天还没学习，连续天数从昨天往回报**，这样"今天尚未开始但前面已连续 N 天"不会被清零，符合用户直觉；一旦今天有记录则从今天起算。

```ts
export function getHomeSummary(): HomeSummary {
  const d = getDb()
  if (!d) return { todayMinutes: 0, todayPomos: 0, streakDays: 0 }
  const today = todayLocal()

  const todayRow = d.prepare(
    `SELECT COALESCE(SUM(minutes),0) AS minutes,
            COALESCE(SUM(pomos),0) AS pomos
     FROM study_stats WHERE date = ?`
  ).get(today) as { minutes: number; pomos: number }

  const rows = d.prepare(
    `SELECT date FROM study_stats
     GROUP BY date HAVING SUM(minutes) > 0
     ORDER BY date DESC`
  ).all() as Array<{ date: string }>
  const studied = new Set(rows.map(r => r.date))

  let streak = 0
  const cursor = new Date()
  if (!studied.has(today)) cursor.setDate(cursor.getDate() - 1)
  while (studied.has(localDate(cursor))) {
    streak++
    cursor.setDate(cursor.getDate() - 1)
  }
  return {
    todayMinutes: todayRow.minutes,
    todayPomos: todayRow.pomos,
    streakDays: streak
  }
}

function localDate(d: Date): string {
  const mm = String(d.getMonth() + 1).padStart(2, '0')
  const dd = String(d.getDate()).padStart(2, '0')
  return `${d.getFullYear()}-${mm}-${dd}`
}
```

> **本地时区注意**：连续天数按本地日期计算，与 `todayLocal()` 保持一致；如需服务端时区校验（§2.9 可选），在本函数加一个可注入时钟参数即可，MVP 不做。

## 4. IPC 与 preload 扩展

### 4.1 通道声明（ipc.ts）

在 `stats` 分组下新增一个通道，命名与既有 `dayTrend / modeCompare / heatmap` 风格一致。

```ts
export const IPC_CHANNELS = {
  // ...既有分组...
  stats: {
    dayTrend: 'stats:day-trend',
    modeCompare: 'stats:mode-compare',
    heatmap: 'stats:heatmap',
    homeSummary: 'stats:home-summary'   // 新增
  },
  // ...
} as const
```

> **白名单自动生效**：`IPC_WHITELIST` 由 `Object.values(IPC_CHANNELS)` 扁平化生成，新增通道无需另行登记。

### 4.2 处理器（storage/stats.ts）

实际处理器只需一行：

```ts
import { getHomeSummary } from './db'
import type { HomeSummary } from '../../shared/stats'

export function registerStatsIpc(): void {
  // ...既有 dayTrend / modeCompare / heatmap...
  ipcMain.handle(IPC_CHANNELS.stats.homeSummary, (): HomeSummary => getHomeSummary())
}
```


## 5. 渲染层组件

### 5.1 homeStore（新文件）

```ts
// src/renderer/src/store/homeStore.ts
import { create } from 'zustand'
import type { HomeSummary } from '../../../shared/stats'

interface HomeStore {
  summary: HomeSummary | null
  loading: boolean
  load: () => Promise<void>
}

export const useHomeStore = create<HomeStore>((set) => ({
  summary: null,
  loading: false,
  load: async () => {
    set({ loading: true })
    try {
      const summary = await window.api.stats.homeSummary()
      set({ summary, loading: false })
    } catch {
      set({ loading: false })
    }
  }
}))
```

在 `HomePage` 挂载与 `timer:complete` 事件时调用 `load()`，确保一场番茄结束后统计即时刷新。

### 5.2 StatsBar 改造（真实数据 + 加载态）

```tsx
// src/renderer/src/components/StatsBar.tsx
import { useEffect } from 'react'
import { useHomeStore } from '../store/homeStore'

function formatMinutes(m: number): string {
  if (!m) return '0m'
  const h = Math.floor(m / 60), mm = m % 60
  return h > 0 ? `${h}h ${mm}m` : `${mm}m`
}

function StatsBar(): JSX.Element {
  const { summary, loading, load } = useHomeStore()
  useEffect(() => { void load() }, [load])

  return (
    <div className="stats-bar">
      <StatCard loading={loading} label="今日专注"
        value={summary ? formatMinutes(summary.todayMinutes) : '--'} />
      <StatCard loading={loading} label="完成番茄"
        value={summary ? String(summary.todayPomos) : '--'} />
      <StatCard loading={loading} label="连续天数"
        value={summary ? String(summary.streakDays) : '--'} />
    </div>
  )
}

function StatCard(p: { loading: boolean; label: string; value: string }): JSX.Element {
  return (
    <div className={p.loading ? 'stat-card loading' : 'stat-card'}>
      <div className="stat-value">{p.value}</div>
      <div className="stat-label">{p.label}</div>
    </div>
  )
}
```

加载态用骨架占位（CSS 加一个淡色 pulse 动画），避免数字闪烁。保留现有 `.stats-bar / .stat-card` 样式不动。

### 5.4 DurationConfigModal 组件（新文件）

进入任一模前弹出时长配置浮层（§2.2）。专注模式是真正的倒计时，直接决定番茄时长；视频学习/英语是开放式学习会话，这里的"时长"作为会话上限（回传给模式页，由页面决定用途）。

```tsx
// src/renderer/src/components/DurationConfigModal.tsx
export type ModeTarget = 'focus' | 'bili' | 'english'

interface Props {
  open: boolean
  mode: ModeTarget | null
  defaultMin: number
  onCancel: () => void
  onConfirm: (minutes: number) => void
}

const FOCUS_PRESETS = [25, 45, 60, 90]
const SESSION_PRESETS = [60, 120, 240]   // 视频学习/英语会话上限（分钟）
```

交互：预设按钮 + 自定义数字输入（clamp 到合法区间），确认后 `onConfirm(minutes)`。专注默认值取 `settings.pomodoro.focusMin`。

## 6. 页面组装与交互流程

### 6.1 HomePage 重组

```tsx
// src/renderer/src/pages/HomePage.tsx
import { useState } from 'react'
import StatsBar from '../components/StatsBar'
import ModeCard from '../components/ModeCard'
import DurationConfigModal, { type ModeTarget } from '../components/DurationConfigModal'
import { useFocusStore } from '../store/focusStore'

interface Props { onNavigate: (page: 'focus' | 'bili' | 'english') => void }

function HomePage({ onNavigate }: Props): JSX.Element {
  const [target, setTarget] = useState<ModeTarget | null>(null)
  const focusStart = useFocusStore((s) => s.start)

  const handleConfirm = async (minutes: number): Promise<void> => {
    const t = target
    setTarget(null)
    if (!t) return
    if (t === 'focus') {
      await focusStart('countdown', minutes * 60_000)   // 直接启动 + 强制会话
    }
    onNavigate(t)   // focus / bili / english 统一跳转
  }

  return (
    <div className="home">
      <h1 className="page-title">首页</h1>
      <StatsBar />
      <div className="mode-grid">
        <ModeCard mark="▶" title="视频学习" accent="#ff6b4a"
          tagline="输入学习主题，进入锁定网页学习"
          highlights={['WBI 搜索', '导航管控', 'AI 助手 + 记事本']}
          onClick={() => setTarget('bili')} />
        <ModeCard mark="A" title="英语学习" accent="#4da3ff"
          tagline="与 AI 母语者对话，分层教学"
          highlights={['分层 Prompt', 'RAG 权威词典', '生词本']}
          onClick={() => setTarget('english')} />
        <ModeCard mark="⚡" title="专注模式" accent="#3ddc97"
          tagline="正/逆序计时 + 番茄循环"
          highlights={['分心拦截', '白噪音联动', '强制锁定']}
          onClick={() => setTarget('focus')} />
      </div>
      <DurationConfigModal open={!!target} mode={target}
        defaultMin={25} onCancel={() => setTarget(null)} onConfirm={handleConfirm} />
    </div>
  )
}
```

### 6.2 App 传导航回调

```tsx
// src/renderer/src/App.tsx · renderPage 中
case 'home':
  return <HomePage
    onNavigate={(page) => setPage(page)}
  />
```

`ModeTarget` 与 `PageKey` 的子集一一对应，跳转复用侧边菜单同一 `setPage`，无额外路由。

### 6.3 交互流程

| 场景 | 步骤 |
|---|---|
| 点击「专注」卡片 | 弹浮层选时长 → 确认 → `focusStore.start` 启动倒计时（触发现行强制会话）→ 跳转专注页 |
| 点击「视频学习」卡片 | 弹浮层选会话上限 → 确认 → 跳转 视频学习页（进入后强制锁定属文档 ②） |
| 点击「英语学习」卡片 | 弹浮层选会话上限 → 确认 → 跳转英语页 |
| 统计条刷新 | 挂载时 `load()`；订阅 `timer:complete` 后再次 `load()` |

## 7. 验收标准

- 首页显示三张模式卡片，点击均弹出时长配置浮层，确认后正确跳转对应页面。
- 专注卡片确认后立即开始倒计时并进入强制会话（复用现有 `timer:start` 链路）。
- 统计条三格显示真实值：今日专注用「Xh Ym / Ym」，完成番茄为整数，连续天数为整数；加载中显示骨架。
- 完成/强制结束一场番茄后，返回首页统计条数字即时更新（无需刷新）。
- SQLite 不可用（`getDb()` 返回 null）时首页不崩溃，统计条显示占位。
- 连续天数口径正确：今天未学返回昨天起算的连续值；历史有空档则中断。
