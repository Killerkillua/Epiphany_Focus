# Changelog

本文件格式遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

**版本唯一来源**：`package.json` 的 `version` 字段。发版前只改这一处，并打同名 Git tag（`vX.Y.Z`），CI 版本守卫会校验 tag 与 `package.json` 一致。

**发版流程**：将 `[Unreleased]` 下的条目移到新版本段落（如 `[1.2.0] - YYYY-MM-DD`），并把同一段说明写入 GitHub Release notes（供应用内更新弹窗的 `releaseNotes` 展示）。
