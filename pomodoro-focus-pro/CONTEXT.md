# Context

> 本文件为项目上下文速查：术语 → 当前实现口径（与 `global.css` / `App.tsx` / `shared/bili.ts` 对齐）。
> 布局体系详见 `docs/window-fullscreen-adaptive-layout-design.md` 与 `docs/adr/0001-fluid-container-driven-layout.md`。

## Glossary

| Term             | 当前实现（已落地）                                                                                                                                                                                                                                      | 说明                                                                                                                                                                        |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Sider            | antd Layout 侧边导航栏：`collapsible`，展开 **240px** / 折叠 **56px**（`collapsedWidth`），Ultrawide（≥1600px）CSS 封顶 **280px**（`!important`）                                                                                                       | `App.tsx` 的 `width={240} collapsedWidth={56} breakpoint="md"`；不采用 clamp() 流体宽度，折叠/封顶由固定值 + 媒体查询控制                                                   |
| app-content      | 主内容区域：`max-width: var(--content-max)`（1200px）+ `margin-inline: auto`，`padding: var(--space-lg) var(--space-xl)`，容器上下文 `container-type: inline-size; container-name: page`                                                                | 数据型页面（`.page-dashboard`，统计 / B 站）在 Wide（≥1200px）放宽到 `--dashboard-max`（1600px）                                                                            |
| focus-layout     | 专注页两栏布局：`flex` 主区 + `.focus-side`，默认（<768px）堆叠单栏、`@media (min-width: 768px)` 起横排双栏                                                                                                                                             | 主窗口 minWidth 940 → <768px 段实际不触发（保留兼容）                                                                                                                       |
| focus-side       | 专注页右侧栏：`width: clamp(240px, 22vw, 340px)`；`container-type: inline-size`                                                                                                                                                                         | ✅ 已实现                                                                                                                                                                   |
| english-layout   | 英语学习页两栏布局：聊天 `flex:1` + `.english-side`，默认（<768px）堆叠单栏、`@media (min-width: 768px)` 起横排双栏                                                                                                                                     | 同 focus-layout 断点策略                                                                                                                                                    |
| english-side     | 英语页右侧栏：`width: clamp(220px, 20vw, 320px)`；`container-type: inline-size`                                                                                                                                                                         | ✅ 已实现                                                                                                                                                                   |
| ai-settings      | 英语页 AI 设置卡片：`width: clamp(200px, 18vw, 300px)`                                                                                                                                                                                                  | ✅ 已实现                                                                                                                                                                   |
| bili-grid        | B 站搜索结果卡片网格：`repeat(auto-fill, minmax(min(100%, 200px), 1fr))`，`gap: var(--space-md)`                                                                                                                                                        | ✅ 已实现                                                                                                                                                                   |
| mode-grid        | 首页模式卡片网格：`repeat(auto-fill, minmax(min(100%, 260px), 1fr))`，`gap: var(--space-md)`                                                                                                                                                            | ✅ 已实现                                                                                                                                                                   |
| settings-layout  | 设置页卡片网格：`repeat(auto-fit, minmax(min(100%, 340px), 1fr))`，`gap: var(--space-sm)`                                                                                                                                                               | ✅ 已实现                                                                                                                                                                   |
| DesignToken      | CSS 自定义属性：`--space-*` / `--text-*`（流体 clamp 尺度）、`--content-max: 1200px`、`--dashboard-max: 1600px`、断点 token `--bp-compact/--bp-medium/--bp-wide`                                                                                        | `global.css` `:root`；`@media` 条件不能引用 var()，断点 token 仅文档性对齐                                                                                                  |
| Breakpoint       | 四档内容驱动断点：**Compact <768px / Medium 768–1200px / Wide 1200–1600px / Ultrawide >1600px**                                                                                                                                                         | 主窗口 minWidth 940px → Compact 实际不触发（保留供 B 站窗口/未来）；实现以 `@media (min-width: 1200px / 1600px)` + antd Sider `breakpoint="md"`（768px）+ `@container` 承担 |
| ContainerContext | 容器查询上下文：`.app-content`（`container-name: page`）、`.focus-side` / `.english-side`（`container-type: inline-size`）                                                                                                                              | 组件级 `@container page` 规则见 `global.css` 阶段三                                                                                                                         |
| OverlayApp       | 悬浮面板独立应用（`#overlay` 路由）：**展开态 610×940**（`OVERLAY_EXPANDED_SIZE`），最小窗口 610×940，`resizable`（系统级缩放）、`movable`（header 原生拖拽）、L0/L1 可最小化；状态机 3 态 expanded / minimized / hidden（**已删除 collapsed 悬浮球**） | 尺寸/状态常量见 `src/shared/bili.ts`；窗口管理见 `src/main/navigation/biliWindow.ts`                                                                                        |
| ScrollArea       | 自定义滚动区组件（`src/renderer/src/components/ScrollArea.tsx`）：JS 渲染胶囊滑块（8px / 99px 圆角 / 浅色），原生滚动条撑出可视区裁剪隐藏                                                                                                               | 全局 `::-webkit-scrollbar` 与 antd 内置虚拟滚动条统一为 8px 浅色胶囊（`--rc-virtual-list-scrollbar-bg` 覆盖）                                                               |
