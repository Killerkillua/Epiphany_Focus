## 填写示例（以"悬浮球拖动窗口变大"为例）

### 1. 问题概述
B 站学习模式学习助手悬浮球，鼠标按住拖动后悬浮窗口不断变大。

### 2. 现象描述
- 复现步骤：1) 打开 B 站学习模式并打开视频；2) 面板折叠为悬浮球；3) 按住球体拖动。
- 实际表现：拖动过程中窗口尺寸持续增大，最终覆盖屏幕。
- 期望表现：拖动仅移动窗口位置，尺寸保持不变。

### 3. 相关代码片段
```typescript
// 文件路径: src/renderer/src/overlay/useWindowDrag.ts
// 行号: 45-61
const onMove = (ev: PointerEvent): void => {
  const d = dragRef.current
  if (!d || ev.pointerId !== d.pointerId) return
  const dx = ev.screenX - d.lastX
  const dy = ev.screenY - d.lastY
  d.lastX = ev.screenX
  d.lastY = ev.screenY
  if (Math.abs(dx) + Math.abs(dy) > 2) {
    if (!d.moved) { d.moved = true; setDragging(true) }
    void window.api.bili.overlayMoveBy(dx, dy).catch(() => {})
  }
}
```

### 4. 错误信息
- 控制台报错：无。
- 异常行为：窗口尺寸随拖动持续增大。
- 触发条件：Windows 高 DPI 缩放（125%/150%）下复现。

### 5. 期望功能
- 交互方式：删除悬浮球状态，直接使用展开态助手；在窗口四角按下鼠标，按拖动方向与距离实时调整 x/y/width/height。
- 边界条件：以对角为锚点等比例缩放，最小窗口 510×840。
- 状态管理：窗口尺寸由主进程统一管理，渲染层仅上报增量。

### 6. 约束与要求
- 必须通过 TypeScript 类型检查；保持 IPC 白名单机制；兼容 Windows 高 DPI。

### 7. 验收标准
- [ ] 四角拖拽可等比例缩放且最小 510×840。
- [ ] 拖动不再导致窗口变大。
- [ ] 通过 `npm run typecheck` 与本地运行验证。
