# 通用学习来源

视频学习不再只有 B 站一条链路。B 站、本地视频和白名单网站共用同一个全屏学习窗口、悬浮助手、笔记和进度。

## 来源

- B 站：保留 WBI 搜索和四层导航。接口或风控失败只影响这一入口。
- 本地视频：系统文件选择器选择文件。主进程校验扩展名和大小后发放内存令牌，播放器通过 `tomato-media://` 读取。渲染层拿不到绝对路径。稳定格式是常见 H.264/AAC MP4；MKV / FLV 会提示转换为 MP4，不内置 FFmpeg，也不调用系统播放器。
- 学习网站：设置中保存域名和可选路径前缀。空路径前缀表示放行该主机。网站在 `persist:learning-web` 分区中打开以保留登录，并与主界面隔离。默认拒绝下载、定位、摄像头和麦克风。

## 安全边界

白名单和全屏锁用于减少专注时随手跳走。它们不是网站安全背书，也不是操作系统级强制。用户仍可以结束进程或在系统播放器中打开同一文件。

旧进度和笔记继续使用原来的 `bvid` 主键。迁移会补上 `resource_key`，既有 BV 记录记为 `bili:<BV>`。
