# 静界专注（Epiphany Focus）

强制专注番茄钟桌面应用，基于 **Electron 33 + React 18 + TypeScript** 构建。通过番茄工作法结合强制防打扰机制（全屏遮罩、快捷键拦截、进程守护等），帮助用户进入深度专注状态；内置 AI 助手、白噪音、视频学习与英语学习模式，兼顾「专注」与「学习」两大场景。

## 快速开始

```bash
# 1. 安装依赖
cd pomodoro-focus-pro
npm install

# 2. 配置 AI Key（可选，留空则走演示模式）
#    复制 .env 文件并按需填写，或首次启动后在「设置 → AI」中填写
#    POMODORO_AI_API_KEY=sk-xxxx

# 3. 启动开发模式（electron-vite dev --watch）
npm run dev

# 4. 类型检查 / 测试 / 代码规范
npm run typecheck    # 主进程 + 渲染层联合类型检查
npm test             # vitest run
npm run lint         # eslint .
npm run format       # prettier --write .

# 5. 采样素材生成与校验（可选）
npm run samples:generate
npm run samples:validate

# 6. 构建安装包
npm run build:win    # Windows（NSIS 安装包）
npm run build:mac    # macOS（DMG）
npm run build:linux  # Linux（AppImage）
```

> 敏感配置（如 `.env`）已被 `.gitignore` 排除，请勿将真实 Key 提交到仓库。

## 功能特性

### 核心专注

- **番茄钟计时**：支持专注 / 短休 / 长休三阶段配置，逆序倒计时与正序累加两种模式，会话统计与连续专注追踪，长休息间隔可配（默认每 4 个番茄一次长休息）。
- **强制专注引擎**：专注期间按锁定等级开启全屏遮罩、全局快捷键拦截、任务栏隐藏、分心应用强关、前台窗口拉回等防打扰机制，并支持紧急退出兜底与重启恢复会话。
- **悬浮面板**：独立小窗展示会话进度、笔记与 AI 聊天，可展开 / 最小化 / 隐藏，专注期间不离开当前窗口即可操作。

### 学习模式

- **视频学习模式**：内置搜索（WRI/WBI 签名）、图片代理（绕过 CDN 防盗链 403）与全屏锁定，四层导航判定管控跳转，专注期间直接学习视频内容。
- **英语学习模式**：AI 对话 + 笔记记录 + 生词本 / 语法要点，支持接入本地大模型 API（OpenAI 兼容协议），单会话提问上限可配。

### 辅助能力

- **AI 助手**：多模态对话、OCR 识别、RAG 检索（本地 SQLite 向量存储），BYOK 自带 Key，留空走演示模式。
- **白噪音**：合成层（白 / 粉 / 棕噪）+ 采样层（雨声、咖啡厅、森林、图书馆、海浪、篝火、风扇、鸟鸣共 8 种自然素材），支持无缝循环、交叉淡入淡出与多轨混合，全局热键调节音量。
- **数据管理**：本地 SQLite 持久化（6 张规约表），支持进度统计图表、自动备份（每日 / 每周）与恢复、备份份数保留策略。
- **自定义设置**：AI Key（BYOK）、番茄参数、锁定等级、到点动作、噪音与学习配置、学习目标、自动备份等，轻量配置统一存于 electron-store。

## 锁定等级

强制专注引擎提供三档可配置的锁定强度，由用户在设置中按需选择（默认 L1）：

| 等级 | 说明 | 能力 |
| --- | --- | --- |
| **L0 轻量** | 置顶 + 提醒，全部可绕过，首次引导默认 | 窗口置顶 |
| **L1 标准** | 全屏遮罩 + 全局快捷键拦截 + 任务栏隐藏 + 分心应用强关 + 前台拉回 | L0 基础上增加全屏遮罩、快捷键拦截（F11/Ctrl+T/Ctrl+W/Ctrl+R/F5）、任务栏隐藏、分心强关、失焦拉回 |
| **L2 强化** | L1 + 守护进程每 2 秒自检拉起 + 关闭任务管理器 + 重启恢复会话 | L1 基础上增加守护进程自检拉起、关闭任务管理器、重启恢复强制会话（防重启绕过） |

> 以上「强制」均为自律辅助而非安全边界，详见下文「威胁模型」。L3 内核级锁定不做（需 EV 签名 / 公证，成本极高，远期评估）。专注会话时长设有上限（默认 4 小时，可配），防止误锁过久。紧急退出需输入恢复码，恢复码仅存 bcrypt 哈希不可逆。

## 架构概览

采用 Electron 三进程模型（主 / 预加载 / 渲染），主进程按领域拆分为独立模块，由 `ipc.ts` 装配层统一注册：

- **enforcement（强制引擎）**：锁定分级（L0/L1/L2）、计时联动、紧急退出、分心拦截、守护进程。专注会话状态持久化，重启后自动恢复，防止用户通过重启绕过锁定。
- **navigation（视频学习模式）**：WBI 签名搜索、播放窗口管理、四层导航判定（白名单 / 黑名单管控跳转）、`bili-image://` 图片代理（Referer 注入 + 磁盘缓存，绕过 CDN 防盗链 403）、全屏锁定。
- **ai（AI 网关）**：分层 Prompt、OCR 识别、RAG 检索（本地 SQLite 向量存储）、BYOK。英语模式提供对话 + 生词本 / 语法要点。
- **audio（白噪音）**：合成层（白 / 粉 / 棕噪，零成本）+ 采样层（8 种自然素材），双节点交叉淡入淡出无缝循环，`tomato-audio://` 自定义协议传输音频流，全局热键调节音量。
- **session（学习会话）**：视频学习 / 英语模式的轻量计时，与强制引擎解耦，计时开始后对主窗口施加与专注模式一致的全屏遮罩（可配）。
- **storage（持久化）**：中央 SQLite（6 张规约表）+ electron-store 轻量配置 + 自动备份调度（每日 / 每周，过点补备）。

### 安全设计

- `contextIsolation: true`、`nodeIntegration: false`、`sandbox: false`，预加载脚本桥接 IPC。
- 生产模式关闭 `devTools`，防绕过矩阵。
- 外部链接一律交给系统浏览器，禁止应用内开新窗口。
- 紧急恢复码仅存 bcrypt 哈希，不可逆；至少 8 位且需包含两类字符。
- 紧急退出防暴力破解：每错 3 次锁定一轮，时长指数退避（1 → 2 → 4 分钟 … 上限 6 小时）；失败计数 / 锁定截止 / L2 冷却均持久化，杀进程重启不会清零，且失败在 bcrypt 比对前落盘。
- 强制状态完整性：`recoveryCodeHash`、`enforced`、`lockLevel`、`sessionMaxHours`、紧急退出状态不再从 `settings.json` 读取，改存 `guard.json` 并附 HMAC-SHA256 签名；密钥经系统凭据库（Electron `safeStorage`，Windows 为 DPAPI）加密存放。直接编辑 `settings.json`（如替换恢复码哈希、清除 `enforced`）无效；运行中改 `guard.json` 会被内存副本自愈覆盖，离线改动会在下次启动时被发现并按 fail-safe 重置（强制会话解除、需重新设置恢复码）。

### 威胁模型

**本应用的「强制」是自律辅助，不是安全边界。**

- 防御对象：分心时的冲动操作与随手绕过（关窗口、切应用、重启、改配置文件、暴力猜恢复码）。
- 不防御：对本机有完整控制权、有意绕过的用户。例如：
  - 用 PowerShell / `wmic` / Process Explorer / `taskkill` 同时结束主进程与守护进程（应用只会持续关闭 `taskmgr.exe`，无法阻止其他工具）；
  - 守护进程是普通的 `node` / 应用子进程，`--install-service` 仅为 `sc create`，未限定运行账户与权限，不构成受保护服务；
  - 同一系统用户可调用同一套 DPAPI 解出签名密钥，或删除 `guard.json` + `guard.key` 回到全新安装状态，或回滚到旧的合法签名副本；
  - 修改系统时间、安全模式启动、卸载应用等。
- 需要真正的强制（内核级 / 受保护服务 / 家长控制）请使用操作系统级方案；L3 内核级锁定当前不做。
- 全局异步异常兜底（`unhandledRejection` / `uncaughtException`），记录日志不静默崩溃。
- 自定义协议遵循最小权限原则（`bili-image://` 不授予 `bypassCSP` 后门特权）。
- 匿名使用统计默认关闭，开启后仅记录本地计数 / 时长事件，不上送任何内容 / URL / 笔记文本，可随时一键关闭。

## 白噪音预设

| 预设 | 说明 |
| --- | --- |
| 白噪 / 粉噪 / 棕噪 | 合成层，零成本，素材未打包时仍可用 |
| 雨声 | 单采样轨 |
| 咖啡厅 | 采样 + 棕噪背景（0.25） |
| 森林 | 采样 + 鸟鸣（0.5） |
| 图书馆 | 采样 + 粉噪背景（0.3） |
| 海浪 | 采样 + 棕噪背景（0.3） |
| 篝火 | 采样 + 棕噪背景（0.3） |
| 风扇 | 单采样轨 |
| 鸟鸣 | 单采样轨（0.8） |

> 采样轨在素材文件打包后自动生效；交叉淡入淡出 1.5 秒，合成缓冲 4 秒。专注开始时可配置自动播放，休息时支持暂停 / 降音量 / 不变三种动作。
